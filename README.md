# Duenda — gizlilik, kullanım koşulları ve destek

Duenda: Çift Ajandası uygulamasının App Store için gereken herkese açık sayfaları. GitHub Pages ile yayınlanır.

| Sayfa | Türkçe | English |
|---|---|---|
| Gizlilik politikası | /tr/gizlilik.html | /privacy.html |
| Kullanım koşulları | /tr/kosullar.html | /terms.html |
| Destek ve hesap silme | /tr/destek.html | /support.html |

Uygulamanın kodu ayrı (private) bir repoda. Görünüm uygulamanın varsayılan teması Gece Masalı'dır (açık ve koyu mod). Yazı tipi uygulamadaki gibi Plus Jakarta Sans (OFL, `fonts/OFL-PlusJakartaSans.txt`); Latin ve Türkçe karakterlerle alt kümelenip WOFF olarak siteye gömülüdür, Google Fonts'a istek gitmez. İkon ve Duenda görselleri uygulamanın kendi görsellerinden küçültülmüştür (`img/`, `favicon.ico`, `apple-touch-icon.png`).
